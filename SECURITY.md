# Security

## Reporting vulnerabilities

Use [GitHub Security Advisories](https://github.com/forkwright/thumos/security/advisories/new) to report vulnerabilities privately.

Include:
- Description of the vulnerability
- Steps to reproduce
- Affected components

Do not open a public GitHub issue for security vulnerabilities.

## Response

Acknowledgment within 48 hours. Fix or mitigation within 7 days for critical issues.
